# Moodify 🎵

Moodify is an AI-powered emotion-based music recommendation system. It detects the user's facial emotion and plays songs based on mood.

## Features

- Real-time facial emotion detection
- Happy, Sad, Neutral mood classification
- Mood-based random song recommendation
- Auto music playback
- Login and Register
- MongoDB song database
- ImageKit media storage
- Bulk song upload

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Redis
- ImageKit
- Face Detection / Emotion Detection
